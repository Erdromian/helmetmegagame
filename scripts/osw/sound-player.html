Ravenheart Sound Board

The 662 sounds exported from OpenSourceWeb into assets/osw-sounds/, grouped by what a sound is for. Click one to hear it. Nothing downloads until you do — each file streams from the source repository at commit .

Where these come from. OpenSourceWeb, the open-licensed archive of the BYOND game Lifeweb / Farweb. Its icons and sounds are CC BY-SA 3.0; the code is not, and none of it is here. Source: SS13-Special-Codebases-Archive/OpenSourceWeb.

This board plays the exported set. The full source tree holds 3,559 files and 484 MB, most of it unusable here — 616 vox words, 170 MIDI files, the piano and violin note banks, 229 MB of jukebox music. To pull something this export left behind, edit the lists in scripts/osw/export-sounds.py and run it again.
